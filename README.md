# steerkey

Steer identifiers and key tokens for idempotent workflows.

**Site:** https://theworker02.github.io/steerkey/

## Install / run

```bash
git clone https://github.com/theworker02/steerkey.git
cd steerkey
node src/cli.js
node --test
```
